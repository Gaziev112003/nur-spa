# Решения

## Шаг 4. Выбор направления
Выбран вариант 3 «Дом на склоне» (песочный и изумрудный, тонкий линейный орнамент, арка, Geologica).
Остальные варианты лежат в `src/variants/v1.tsx` … `v5.tsx` и открываются по `variants/1/` … `variants/5/`.

Причина выбора: направление узнаётся как дагестанское без клише (нет мечетей со стока, полумесяцев, золота на чёрном);
цвет держит страницу крупными площадями, а не акцентной кнопкой; арка работает и как маска под кадр, и как знак.

## Шаг 5. Три темы внутри одной системы
Сетка, шрифты, шкала и скругления общие. Меняются только цвета через `data-theme`:
- `laser` — жемчужный белый фон, холодная сталь, розово-пудровый акцент;
- `plasma` — графит, бирюзовый акцент (не фиолетовый, фиолетовые градиенты запрещены);
- `hijama` — песочный фон, изумрудный акцент (базовая тема).
